Step 1: Intuition Playground (30 min)

The Pseudo-Replication Simulator

Neuroscience experiments rarely sample independent units from an infinite pool. When you record 50 cells across 3 mice, your effective sample size is closer to \(N = 3\) than \(N = 150\).

Treating clustered observations as completely independent artificially deflates the Standard Error of the Mean (\(SE = s / \sqrt{N}\)), which inflates test statistics and creates false-positive rates as high as 40–60% at nominal \(\alpha = 0.05\).

Use the simulator below to compare: 1. Pooled Model: Treats every segment/cell as independent. 2. Aggregated (Animal-Averaged) Model: Computes the mean per mouse first, then runs a test with \(N_{\text{animals}}\). 3. Linear Mixed-Effects Model (LMM): Models individual segments while adjusting for grouping via random intercepts.

      actionButton("resim", "Resimulate Experiment", class = "btn-primary"),
      helpText("True treatment effect is zero (H0 is true). Any detection is a Type I error (false positive).")

    )

server <- function(input, output) {
  sim_nested <- reactive({
    input$resim
    n_a <- input$n_animals
    n_c <- input$cells_per_animal
    sd_m <- input$mouse_sd
    
    # Simulate null model (treatment effect = 0)
    ctrl_mouse_means <- rnorm(n_a, mean = 20, sd = sd_m)
    treat_mouse_means <- rnorm(n_a, mean = 20, sd = sd_m)
    
    ctrl_cells <- unlist(lapply(ctrl_mouse_means, function(m) rnorm(n_c, mean = m, sd = 0.8)))
    treat_cells <- unlist(lapply(treat_mouse_means, function(m) rnorm(n_c, mean = m, sd = 0.8)))
    
    df <- data.frame(
      value = c(ctrl_cells, treat_cells),
      group = rep(c("Control", "Treated"), each = n_a * n_c),
      mouse = factor(rep(c(paste0("C_M", 1:n_a), paste0("T_M", 1:n_a)), each = n_c))
    )
    
    # 1. Naive pooled t-test
    p_naive <- t.test(value ~ group, data = df)$p.value
    
    # 2. Aggregated animal-level t-test
    agg_df <- aggregate(value ~ group + mouse, data = df, mean)
    p_agg <- t.test(value ~ group, data = agg_df)$p.value
    
    list(df = df, agg = agg_df, p_naive = p_naive, p_agg = p_agg, n_total = nrow(df), n_mice = n_a * 2)
  })

  output$nestedPlot <- renderPlot({
    res <- sim_nested()
    df <- res$df
    
    par(mar = c(4.5, 4.5, 3, 1))
    # Stripchart showing nested dots by mouse
    plot(as.numeric(df$mouse), df$value, pch = 16, col = rgb(0.2, 0.4, 0.8, 0.4),
         xlab = "Mouse ID", ylab = "Measured Cell Value",
         main = "Nested Sampling: Individual Cells Grouped by Mouse",
         xaxt = "n")
    axis(1, at = 1:res$n_mice, labels = levels(df$mouse), las = 2, cex.axis = 0.8)
    
    # Plot mouse-level means
    points(1:res$n_mice, res$agg$value, pch = 18, col = "firebrick", cex = 2)
    abline(v = res$n_mice / 2 + 0.5, lty = 2, col = "grey50")
    legend("topright", legend = c("Individual Cells", "Animal Mean"),
           col = c("steelblue", "firebrick"), pch = c(16, 18), bty = "n")
  })
  
  output$simStats <- renderPrint({
    res <- sim_nested()
    cat("Total Cells Quantified (N_cells):", res$n_total, "\n")
    cat("Total Mice Used (N_animals):    ", res$n_mice, "\n\n")
    cat("Naive Pooled t-test p-value (ignores clustering):", format.pval(res$p_naive, digits = 4), "\n")
    cat("Summary: ", ifelse(res$p_naive < 0.05, "FALSE POSITIVE CLAIMED!", "Correctly retained H0"), "\n\n")
    cat("Animal-Averaged t-test p-value (respects N_animals):", format.pval(res$p_agg, digits = 4), "\n")
  })
}

shinyApp(ui, server)

Exercise 1: The Trap of Naive Pooling (Ordinary Least Squares)

Fit a standard linear model using lm() that treats each dendritic segment as independent:

# --- BROKEN CODE CHALLENGE: NAIVE POOLING ---
fit_naive <- lm(spine_density ~ treatment + dist_soma_um, data = spines)
summary(fit_naive)

Look at the sample size (\(N \approx 280\)) and the resulting standard errors: * The model assumes each segment was sampled from a completely different biological animal. * Because the clustering of segments within cells and animals is ignored, the standard error for treatment is artificially narrow, producing an overconfident \(t\)-statistic.

Exercise 3: Fitting a Linear Mixed-Effects Model with lme4

Mixed models preserve every observation while explicitly estimating variance components at each hierarchical level:

\[\text{spine\_density}_{ijk} = \beta_0 + \beta_1 \cdot \text{treatment} + \beta_2 \cdot \text{dist} + u_{0, \text{animal}(i)} + u_{0, \text{cell}(ij)} + \epsilon_{ijk}\]

Where: * \(u_{0, \text{animal}} \sim \mathcal{N}(0, \sigma^2_{\text{animal}})\): Random intercept for each mouse. * \(u_{0, \text{cell}} \sim \mathcal{N}(0, \sigma^2_{\text{cell}})\): Random intercept for each neuron nested within a mouse. * \(\epsilon_{ijk} \sim \mathcal{N}(0, \sigma^2_{\text{residual}})\): Segment-level residual variance.

# --- TASK: FIT NESTED LINEAR MIXED MODEL ---
fit_mixed <- lmer(
  spine_density ~ treatment + dist_soma_um + (1 | animal_id / cell_id),
  data = spines
)

summary(fit_mixed)

Inspect the output: 1. Random Effects: Look at Std.Dev. for animal_id, cell_id:animal_id, and Residual. How much variance exists between mice vs. between neurons? 2. Fixed Effects: Notice how the standard error of treatmentStress properly reflects the true animal cohort size (\(N = 8\)), not the total number of segments (\(N = 280\)).
